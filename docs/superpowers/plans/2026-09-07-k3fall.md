# k3fall Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rust server on a Pi 5 that turns the K3's 8.215 MHz IF (via RSP2pro) into a CAT-tracked, click-to-tune, high-definition web waterfall with the "console" UI.

**Architecture:** Single Rust binary. A blocking DSP thread reads IQ from an `IqSource` (SoapySDR or file playback), FFTs at 32k, quantizes rows to u8, and broadcasts them. A CAT task owns the K3 serial port and publishes rig state / accepts tune commands. An axum web server serves the embedded static client and streams per-client shaped rows over one WebSocket.

**Tech Stack:** Rust (tokio, axum, rustfft, serialport, serde, toml, num-complex, anyhow, tracing), vanilla JS + 2D canvas client, SoapySDR behind a cargo feature.

**Spec:** `docs/superpowers/specs/2026-09-07-k3fall-design.md`

## Global Constraints

- Rust edition 2021; quality gate before every commit: `cargo fmt -- --check && cargo clippy -- -D warnings && cargo test`.
- SoapySDR is behind cargo feature `soapy` (off by default) so the project builds and tests on macOS without native libs.
- DSP defaults: fft_size 32768, sample_rate 250_000, rows_per_sec 30, ref_level_db −30.0, range_db 90.0.
- Binary row frame header is exactly 19 bytes LE: seq u32, center_rf_hz u64, span_hz u32, bins u16, flags u8.
- Quantization: 255 = ref_level_db, 0 = ref_level_db − range_db, clamped.
- Rows are fft-shifted: bin 0 = lowest RF frequency of the span.
- K3 CAT: Kenwood-style ASCII, `;` terminated, 11-digit frequencies, tune rounds to 10 Hz.
- Client visual contract: `mockups/console.html` (colors, fonts, layout).

```rust
use anyhow::Result;
use num_complex::Complex;
use std::f32::consts::TAU;
use std::path::Path;

pub trait IqSource: Send {
    fn read(&mut self, buf: &mut [Complex<f32>]) -> Result<usize>;
    fn sample_rate(&self) -> u32;
}

pub struct FileSource {
    samples: Vec<Complex<f32>>,
    pos: usize,
    sample_rate: u32,
}

impl FileSource {
    pub fn from_samples(samples: Vec<Complex<f32>>, sample_rate: u32) -> Self {
        assert!(!samples.is_empty());
        Self { samples, pos: 0, sample_rate }
    }

    pub fn open(path: &Path, sample_rate: u32) -> Result<Self> {
        let bytes = std::fs::read(path)?;
        let samples = bytes
            .chunks_exact(8)
            .map(|c| {
                let re = f32::from_le_bytes(c[0..4].try_into().unwrap());
                let im = f32::from_le_bytes(c[4..8].try_into().unwrap());
                Complex::new(re, im)
            })
            .collect::<Vec<_>>();
        anyhow::ensure!(!samples.is_empty(), "empty IQ file");
        Ok(Self::from_samples(samples, sample_rate))
    }

    pub fn read(&mut self, buf: &mut [Complex<f32>]) -> Result<usize> { /* trait impl body below */ }
}

impl IqSource for FileSource {
    fn read(&mut self, buf: &mut [Complex<f32>]) -> Result<usize> {
        for out in buf.iter_mut() {
            *out = self.samples[self.pos];
            self.pos = (self.pos + 1) % self.samples.len();
        }
        Ok(buf.len())
    }
    fn sample_rate(&self) -> u32 { self.sample_rate }
}

pub fn tone(sample_rate: u32, freq_hz: f32, amplitude: f32, len: usize) -> Vec<Complex<f32>> {
    (0..len)
        .map(|n| {
            let ph = TAU * freq_hz * n as f32 / sample_rate as f32;
            Complex::new(amplitude * ph.cos(), amplitude * ph.sin())
        })
        .collect()
}
```

(Drop the stray inherent `read` — only the trait impl. Keep `FileSource` free

Core details the implementer needs:
- Hann window `0.5 * (1 - cos(TAU * n / (N-1)))`, precomputed.
- Hop size `hop = sample_rate / rows_per_sec` (integer). Maintain a ring
  buffer (`VecDeque<Complex<f32>>`). On each `process` call append samples;
  while `buffer.len() >= fft_size`: copy first `fft_size` into scratch,
  window, run `rustfft` forward, compute `db[i] = 10 * log10(norm_sqr / (N*N) + 1e-20)`,
  fft-shift (second half then first half → output index 0 is −fs/2),
  quantize, push row, then `drain(..hop)`.
- If `hop > fft_size` this still works (drain min(hop, len)); guard with
  `let hop = hop.max(1);`.
- `run_dsp_thread`: read chunks of `hop` samples into a reusable buffer,
  call `process`, `tx.send(SpectrumRow { .. })` ignoring lag errors; if
  `pace`, sleep `hop as f64 / sample_rate as f64` per read using
  `std::thread::sleep`. `seq` is a wrapping u32 counter.

```rust
pub fn shape_row(bins: &[u8], start: usize, end: usize, out_width: usize) -> Vec<u8> {
    let slice = &bins[start..end];
    let n = slice.len();
    let mut out = Vec::with_capacity(out_width);
    for i in 0..out_width {
        let lo = i * n / out_width;
        let hi = ((i + 1) * n / out_width).max(lo + 1).min(n);
        out.push(slice[lo..hi].iter().copied().max().unwrap_or(0));
    }
    out
}
```
